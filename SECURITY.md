# Security Policy

## Reporting a vulnerability

Please report security problems privately using GitHub's **private vulnerability reporting** on the affected repository: open the repo's **Security** tab and choose **Report a vulnerability**.

Please do not open a public issue for a vulnerability, and do not include secrets or exploit details in public places.

Include what you found, how to reproduce it, and which version or commit you tested. I will acknowledge your report as soon as I can and keep you updated on the fix.

## Supported versions

Fixes go to the latest release or the default branch. Older versions are not patched.
