# Getting help

- **Questions and how-to:** read the repository's README and docs first, then open an issue and describe what you tried.
- **Bugs:** open an issue using the bug report form.
- **Feature ideas:** open an issue using the feature request form.
- **Security problems:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

These are personal projects maintained in spare time, so replies may take a while.
